# Phase 1 Sales Copilot Design (Agentic BI)

**Date:** 2026-03-20
**Scope:** Phase 1（增强型数据副驾）
**Primary user:** 业务负责人
**Primary success criterion:** 问答准确率优先

---

## 1. 背景与目标

基于 `docs/RFP.md` 的总体路线，本设计聚焦 Phase 1：在销售域先构建“高准确率、可追溯、可复现”的数据问答副驾能力，为后续 Phase 2（主动诊断）和 Phase 3（执行闭环）打基础。

本阶段不追求全域覆盖与自动执行，聚焦“问得准、答得稳、口径一致”。

---

## 2. 方案对比与选型

### 方案 A（选定）：语义优先 Text-to-Metrics
- LLM 负责意图理解与查询计划生成
- 执行走统一指标语义层/API，而非直接生成复杂 SQL

### 方案 B：NL2SQL 优先 + 自纠错
- 直接生成 SQL，配合 EXPLAIN/LIMIT 回路修正

### 方案 C：双通道混合路由
- 常见问题走语义层，长尾走 NL2SQL

### 选型结论
选择 **方案 A**。原因：准确率、口径一致性、权限治理、审计可追溯能力最佳，最符合当前阶段目标。

---

## 3. 目标架构（Phase 1）

### 3.1 语义指标层（Metrics Semantic Layer）
- 统一定义销售域核心指标：GMV、净收入、毛利额、毛利率、环比/同比等
- 统一定义维度：时间、区域、品类、渠道
- 提供指标查询 API，作为唯一计算入口

### 3.2 意图解析与查询规划器（Intent + Planner）
- 将自然语言问题解析为结构化查询计划（query plan）
- 输出字段：指标、过滤条件、分组维度、时间窗口、比较方式、排序

### 3.3 查询执行与校验器（Execution + Validator）
- 校验 query plan 合法性（指标存在性、维度组合、权限上下文）
- 调用指标 API 执行查询并返回标准结果结构

### 3.4 结果解释与可视化生成器（Narrative + Chart Builder）
- 生成业务可读结论（关键值、变化、贡献维度）
- 自动生成图表配置（趋势、排名、占比等）供前端渲染

### 3.5 会话上下文管理（Conversation Memory）
- 支持追问承接（例如“那华南呢”“按月看”）
- 复用上轮 query plan 进行局部参数替换

### 3.6 权限与审计模块（RBAC + Audit）
- 强制绑定用户身份与数据范围
- 记录问题、query plan、执行摘要、响应元信息

---

## 4. 端到端数据流

1. 用户提问（销售分析问题）
2. 意图解析（识别指标/维度/过滤/时间/比较）
3. 生成 query plan（结构化 DSL）
4. 计划校验（语义层可执行性 + 权限）
5. 指标 API 执行查询
6. 结果后处理（变化计算、TopN、摘要）
7. 返回自然语言结论 + 图表配置
8. 追问场景复用上下文，最小改动重算

### 闭环特性
- **可追溯**：可回溯到 query plan 与指标定义
- **可复现**：同输入在同数据快照下结果一致
- **可审计**：全链路日志可检索

---

## 5. 错误处理与安全治理

### 5.1 错误处理
- 意图不完整：最小澄清（一次问一个缺口）
- 指标未定义：明确提示并给可选近似指标
- 维度组合非法：拒绝执行并给可执行替代
- 权限不足：阻断并返回权限提示（不泄漏越权信息）
- 下游失败/超时：标准错误码、友好提示、完整审计

### 5.2 安全与治理
- 查询强制注入权限上下文
- 指标定义版本化（支持回答关联版本）
- 审计日志覆盖问答链路关键节点
- 输出策略约束，避免暴露敏感字段与内部细节

---

## 6. 测试与验收标准

### 6.1 测试分组
1. **语义口径一致性**：不同问法同口径
2. **链路准确性**：意图解析与追问承接正确
3. **稳定与可恢复**：重复问答稳定、失败可解释
4. **权限与审计**：越权拦截与日志完整

### 6.2 建议验收门槛
- 销售域核心问题集准确率：**≥ 90%**
- 追问上下文承接正确率：**≥ 85%**
- 越权拦截率：**100%**
- 审计记录覆盖率：**100%**

---

## 7. 非目标（Phase 1）

以下内容不纳入当前阶段交付：
- 主动异常监控与自动归因（Phase 2）
- 跨系统动作执行与审批流（Phase 3）
- 多业务域大范围覆盖（后续迭代）

---

## 8. 里程碑建议（对齐 RFP）

- **M1：语义层就绪**（销售域核心指标 + 维度 + API）
- **M2：问答链路跑通**（解析→计划→执行→解释→图表）
- **M3：质量门禁达标**（准确率、权限、审计门槛通过）
- **M4：小范围试点**（业务负责人真实问题回放与调优）
